# 🛒 Walmart Sales Analysis

## 📌 Project Overview

This project performs an exploratory data analysis (EDA) on a Walmart sales dataset using Python. The goal is to uncover meaningful business insights by analyzing sales performance, customer purchasing patterns, product categories, and overall revenue trends.

The project demonstrates practical data analysis skills using **Python, Pandas, NumPy, and Matplotlib** while following a structured data analysis workflow.

---

## 🎯 Objectives

* Clean and preprocess the dataset
* Analyze overall sales performance
* Identify top-selling products and categories
* Explore monthly sales trends
* Analyze city-wise sales distribution
* Generate visualizations for better insights
* Summarize key business findings

---
