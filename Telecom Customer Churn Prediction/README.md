# Customer Churn Prediction

A Machine Learning classification project that predicts whether a customer is likely to churn based on their demographic, service, and account-related information.

## 📌 Project Overview

Customer churn is a major challenge for subscription-based businesses. Identifying customers who are likely to leave allows companies to take preventive actions and improve customer retention.

In this project, a supervised machine learning approach is used to predict customer churn.

The complete workflow includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Categorical encoding
- Feature scaling
- Train-test split
- Model training
- Model evaluation
- Churn probability prediction

---

## 🎯 Objective

The main objective of this project is to build a machine learning model that can:

1. Predict whether a customer will churn.
2. Estimate the probability of customer churn.
3. Evaluate the performance of the classification model.

---

## 🗂️ Dataset

The dataset contains customer-level information such as:

- Customer ID
- Demographic information
- Service information
- Account information
- Customer tenure
- Churn status

### Target Variable

`Churn`

| Value | Meaning |
|------:|---------|
| 0 | Customer will not churn |
| 1 | Customer will churn |
